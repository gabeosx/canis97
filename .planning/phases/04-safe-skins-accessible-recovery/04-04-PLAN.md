## Trust Boundaries

| Boundary | Description |
|---|---|
| Validated appearance data → SwiftUI renderer | Imported palette and local-decoration values may influence visual chrome but cannot gain control, semantic, network, persistence, or layout authority. |
| Decorative layer → native controls/accessibility tree | Inert images and surface backgrounds must stay behind real app-owned controls, ignore hit testing, and remain accessibility-hidden. |
| Selected custom appearance → Native recovery | Rendering must use the complete static Native value when a declared asset is unusable, never a mixture of failed custom and Native tokens. |
