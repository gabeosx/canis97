## Phase Goal

**As a** SiriusXM subscriber, **I want to** find my entitled linear channels and reliably control one live stream, **so that** I can listen on my Mac with truthful playback and metadata state.

<objective>
Repair initial and recovery AVFoundation installation order while preserving confirmed state, supersession, and explicit session-end safety.

Purpose: Remove the production readiness/install dependency cycle that currently prevents the sole AVPlayer from loading any resolved item.
Output: One shared install-before-ready coordinator path, synchronous session-end invalidation, and focused production-runtime-shaped tests whose readiness event is impossible before installation.
</objective>

## Trust Boundaries

| Boundary | Description |
|---|---|
| Opaque media handoff → AVPlayerItem/runtime | A resolved item becomes active media authority only while its coordinator generation and selected identity remain current. |
| AVFoundation callbacks → semantic playback state | Asynchronous ready/rate/time-control/failure observations must not publish after command or session supersession. |
| Authentication session end → playback coordinator | Credential/session cleanup must immediately revoke pending media activity without giving playback code secret-store authority. |
