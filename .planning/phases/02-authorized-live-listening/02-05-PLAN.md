## Trust Boundaries

| Boundary | Description |
|---|---|
| Selected catalog identity → tune authorization | A browsable/stale identity requests current authorization but carries none itself. |
| Provider tune/resource/key → opaque handoff | Protected untrusted data must remain fixed-contract, ephemeral, and generation-bound. |
| Opaque handoff → one AVPlayer | Only the app integration runtime may create/install a player item. |
| UI/control command → coordinator state | Untrusted ordering/concurrency must serialize and publish only confirmed current state. |
