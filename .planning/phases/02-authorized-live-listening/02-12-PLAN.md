## Phase Goal

**As a** SiriusXM subscriber, **I want to** find my entitled linear channels and reliably control one live stream, **so that** I can listen on my Mac with truthful playback and metadata state.

<objective>
Create a decisive, privacy-closed native-authentication tracer and make session durability truthful before any new live attempt.

Purpose: The current rejection proves only that one of two native stages returned a 401/403-class response. This plan makes those boundaries testable and observable without another login, then prevents the UI from claiming Ready when Keychain persistence failed.
Output: Fixed stage/outcome diagnostics, distinct unauthorized/forbidden semantics, persistence-gated session results, and a complete injected package matrix.
</objective>
