**As a** SiriusXM subscriber, **I want to** find my entitled linear channels and reliably control one live stream, **so that** I can listen on my Mac with truthful playback and metadata state.

<objective>

Purpose: Complete truthful live listening context while containing provider metadata/artwork volatility and stale-state risk.
Output: Semantic metadata/artwork APIs, strict adapter and timing tests, independent app metadata model, and native fresh/stale/unavailable presentation.
</objective>

## Trust Boundaries

| Boundary | Description |
|---|---|
| Provider metadata JSON → semantic snapshot | Untrusted text, timing hints, and references must be strictly decoded and generation-bound. |
| Artwork reference/bytes → native rendering | Remote data must pass fixed host/type/size/dimension validation without exposing source URLs. |
| Metadata timing/task → playback UI | Metadata may inform presentation but must never gain audio/player authority. |
