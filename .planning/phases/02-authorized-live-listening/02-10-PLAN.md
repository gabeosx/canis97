## Trust Boundaries

| Boundary | Description |
|---|---|
| SwiftUI selection → semantic metadata lifecycle | User selection must start/cancel one generation without bypassing the presentation model or authorizing playback. |
| Provider metadata/artwork → app presentation | Untrusted text/reference/bytes must remain strict, bounded, generation-bound semantic values. |
