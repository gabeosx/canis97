## Phase Goal

**As a** SiriusXM subscriber, **I want to** use a cohesive native macOS player and library, **so that** one shared playback session continues correctly across app and system control surfaces.

<objective>
Connect the one listening session to macOS media keys and Now Playing through a single app-owned MediaPlayer adapter driven only by confirmed semantic state.

Purpose: System controls must be first-class peers of the app windows without multiplying handlers, exposing live-inappropriate commands, creating audio infrastructure, or publishing optimistic/skin-authored metadata.
Output: Injectable system command/info-center adapters, exact command allow-list, confirmed metadata model, and deterministic tests.

Decision coverage: D-12 queue routing, D-13 system-command surface, and D-14 Now Playing precedence are implemented here.
</objective>
