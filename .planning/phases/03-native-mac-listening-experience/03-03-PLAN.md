## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Stored/captured stable IDs → current catalog | Old local/queue identity must be reconciled with current entitled browse data. |
| UI selection → tune command | Selection is untrusted intent and cannot authorize playback. |
| Queue candidate → coordinator | Candidate identity crosses into the existing authorized tune boundary. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Information Disclosure | LibraryView and PlaybackQueue | high | mitigate | Project only semantic stable IDs and allow-listed snapshots; neither component imports session, transport, credential, resource, or stream data. |
| T-03-02 | Elevation of Privilege | PlaybackQueue candidate selection | high | mitigate | Filter against the current entitled semantic snapshot and delegate every tune to PlaybackCoordinator/client authorization; stored/captured presence has no authority. |
| T-03-03 | Denial of Service | reveal and previous/next routing | high | mitigate | No-wrap finite traversal, generation-tagged reveal, one command per activation, and immutable bounded arrays prevent loops/duplicate work. |
| T-03-04 | Tampering | library collection and active markers | high | mitigate | Stable identity drives rows and Now Playing; view selection/search cannot mutate active identity or fabricate entitlement. |
</threat_model>
