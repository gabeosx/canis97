# Phase 3 — UI Design Contract

> Visual and interaction contract for the native macOS listening shell. Generated by gsd-ui-researcher; verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none — this is a native SwiftUI/AppKit application, not a React/Next/Vite project; the shadcn gate is not applicable |
| Preset | not applicable |
| Component library | SwiftUI native controls, with focused AppKit bridges only for compact-window behavior, Always on Top, and window restoration |
| Icon library | SF Symbols; pair every icon-only action with an explicit accessibility label and tooltip |
| Font | SF Pro through SwiftUI system text styles; Dynamic Type and user accessibility settings remain enabled |

### Native presentation seam

Create a renderer-independent compact-player presentation model with semantic slots for: player background, channel identity, artwork, primary and secondary metadata, confirmed playback status, favorite state, transport controls, and error/recovery status. The native renderer is the Phase 3 fallback. No renderer owns playback behavior, accessibility semantics, keyboard commands, persistence, or system-media integration. This seam is required by D-07 so Phase 4 can change bounded appearance without changing those semantics.

## Window and Layout Contract

### Compact player

- Open after an authenticated launch alongside the library window. It is the primary app window; closing it terminates Sirius Mac and normal shutdown ends playback.
- Use one non-resizable **400 × 288 pt** content area. Do not offer full screen, arbitrary resizing, a sidebar, or an embedded web view.
- Restore the last valid on-screen frame; otherwise center on the active display. Persist the compact window frame separately from the Always on Top preference.
- The default layout, top to bottom: channel number/name and favorite action; 72 pt artwork beside two metadata lines; confirmed playback/status line; a three-control transport row (Previous, Play/Pause, Next); then a small `Show Library` action and Always on Top menu item. Preserve this visual order in the accessibility tree.
- The compact player's visual anchor is channel identity and artwork; confirmed playback status and transport controls are secondary. This is the first content that should draw the eye in the populated state.
- Transport controls are native buttons with a visible selected/pressed state. Play/Pause changes label and icon only after the coordinator confirms the state. Never show seek, scrub, duration, or replay UI for live radio.
- Always on Top is off by default, user-controlled, remembered, and represented by a checked app-menu command as well as the compact-player menu. Toggling it changes only window level, not playback or window ownership.

### Library window

- Open after an authenticated launch. Closing it only closes the library; playback and compact player remain intact. `Command-L` reopens or focuses the existing library window, never constructs another playback coordinator.
- Use a resizable native window with default content size **980 × 700 pt** and minimum content size **760 × 540 pt**. Restore its last valid on-screen frame.
- Use a top toolbar with exactly four semantic tabs: **Channels**, **Categories**, **Favorites**, and **Recents**. Tabs are native controls, not custom skin-owned navigation; the selected tab persists locally.
- Place a native search field in the toolbar. `Command-F` focuses it. Search filters only the visible collection and never tunes a channel.
- The content region is a vertically scrolling native list. A row contains a 28 pt artwork placeholder/image, channel number, title, optional category, favorite control, and a persistent Now Playing indicator when its stable channel ID equals the active channel. Artwork failure uses the `photo` SF Symbol placeholder and does not change row height.
- Single click or arrow-key movement changes only browse selection. Double-click or Return tunes the selected row. Browse selection remains independent from active playback; the Now Playing indicator is the sole persistent active-channel marker.
- `Show in Library` switches to Channels, clears any search query that hides the active channel, scrolls it into view, and highlights its Now Playing indicator without overwriting the user's independent browse selection. It is available from compact-player menu and application menu.

### Cross-window and queue behavior

- Both windows, application-menu commands, and system media commands consume one app-owned `PlaybackCoordinator`, one listening model, and one local library store. They must render the same confirmed channel, metadata, playback, favorite, and failure state.
- Previous/Next uses the stable ordered queue captured when tuning began; unchanged tab changes cannot alter it. If that queue is unusable, use the full entitled lineup. Disable the unavailable direction for a one-item queue; never wrap implicitly.
- A successful tune immediately moves or adds the unique stable channel identity to the top of Recents only after playback is confirmed. Persist at most 50 non-secret channel snapshots. Retuning an existing item moves it to the top.
- Favorite/unfavorite is immediate and reversible without confirmation from compact player and all applicable list rows. The toggle uses the same local stable-ID state everywhere.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4pt | Icon-to-label gaps, metadata line separation |
| sm | 8pt | Compact control groups and list-row internal gaps |
| md | 16pt | Default player padding, list-row vertical padding, toolbar grouping |
| lg | 24pt | Library content inset and distinct player sections |
| xl | 32pt | Compact-player section separation and major library gaps |
| 2xl | 48pt | Empty-state vertical separation |
| 3xl | 64pt | Library empty-state top breathing room |

Exceptions: 1pt borders/dividers; macOS native controls must have at least a 28 × 28 pt hit target (32 × 32 pt for compact transport controls). These are accessibility/platform constraints, not free-form spacing values.

## Typography

Use only these four sizes and two weights. Text must scale with the user's system text-size settings; do not substitute skin-supplied fonts in Phase 3.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Label | 12pt | Regular (400) | 1.33 |
| Body | 14pt | Regular (400) | 1.50 |
| Heading | 18pt | Semibold (600) | 1.20 |
| Display | 24pt | Semibold (600) | 1.20 |

- Compact channel identity uses Heading; its number may use Label. Compact metadata uses Body. Library rows use Body with Label for number/category/status.
- Library channel names, categories, tab labels, and toolbar labels truncate at the tail to one line; expose the complete value through VoiceOver and a hover tooltip. Compact primary and secondary metadata each truncate at two lines before the status/control row is displaced.
- Never encode playback, freshness, favorite, or error state with typography alone; retain a text label/icon and accessibility value.

## Color

The following are the native fallback palette for Phase 3. Phase 4 may map these semantic roles to a validated skin palette, but cannot change their meaning, accessible contrast fallback, focus treatment, or state semantics.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#111111` | Compact-player background and library primary surface |
| Secondary (30%) | `#262626` | Player metadata panel, list-row hover/selection surface, toolbar/tab container |
| Accent (10%) | `#C6FF00` | Confirmed Play control, active tab indicator, Now Playing indicator, favorite-on glyph, keyboard focus/selection treatment |
| Destructive | `#FF453A` | Clear Recents confirmation and destructive action only |

Accent reserved for: confirmed live-playback call to action, active library tab, active-channel Now Playing indicator, favorited state, and focused/selected native collection item. It is not a generic color for every button, link, decoration, or error.

- Use primary/secondary system text colors over the fallback surfaces and adjust only through system high-contrast appearance APIs. Accent must never be the sole carrier of state; pair it with a text label, SF Symbol, or selected/checked control state.
- Use the macOS system focus ring or list-selection highlight. Do not invent a low-contrast decorative focus style.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | `Play Live` for confirmed idle/stopped/paused state; `Pause` only when confirmed playing |
| No active playback | `Nothing Playing`; action `Open Library` |
| Empty state heading | `No Favorites Yet` |
| Empty state body | `Select the star beside a channel to keep it here.` For Recents: `Channels you play will appear here.` For an empty entitled lineup: `No entitled channels are available. Refresh the library or sign in again.` |
| Error state | `Playback couldn’t start.` Follow with the confirmed failure-specific action: `Try Again`, `Sign In Again`, or `Refresh Library`; never imply that a channel is playing or a retry is occurring before confirmation. |
| Destructive confirmation | **Clear Recents**: alert title `Clear Recents?`; message `This removes your recently played channels from this Mac. Favorites will not be changed.`; buttons `Keep Recents` (default/cancel) and `Clear Recents` (destructive). |

Use existing confirmed Phase 2 failure distinctions in visible status text: authentication, entitlement, catalog, stream resolution, network, buffering/stall, decoder, and unsupported upstream failures. Metadata may say `Last updated earlier` when stale and `Current program unavailable` when unavailable; it must never invent a track or artist.

## Interaction and Accessibility Contract

| Surface | Contract |
|---------|----------|
| Compact transport | Previous, Play/Pause, and Next expose clear VoiceOver labels and a value that reports confirmed state. Play/Pause announces `Playing` or `Paused` only after coordinator confirmation; unavailable direction reports why it is disabled. |
| Library rows | VoiceOver label includes channel number/name; value appends `Now Playing` and/or `Favorite` when applicable. Selection is announced separately from tuning. A row's favorite button is independently focusable and announces `Add to Favorites` or `Remove from Favorites`. |
| Keyboard | Arrow keys move library selection without tuning; Return tunes selection; Space toggles Play/Pause except while a text input has focus; Command-F focuses search; Command-L shows/focuses library. Each essential action is also exposed through a visible native control or app menu. |
| Focus | Preserve focus when a list refreshes if its stable row remains; otherwise move to the nearest surviving row, then the list itself. Do not steal library focus when playback changes in another surface. Use native macOS row highlight/focus ring. |
| State announcements | Announce confirmed tune, play, pause, favorite change, and terminal playback failure once. Do not repeatedly announce background metadata refreshes; announce a metadata freshness change only when it becomes stale or unavailable. |
| Motion | Use at most a 120 ms opacity transition for library reveal or status changes. With Reduce Motion enabled, use no positional, scale, or looping animation. |
| Pointer and menus | Retain standard native hover, context-menu, and tooltip behavior. Context menus duplicate, rather than replace, visible and keyboard-reachable favorite, tune, and Show in Library actions. |
| System media | Publish Now Playing only from confirmed coordinator/metadata state: title+artist first; otherwise current program, then channel name; channel artwork is context. Expose only Play/Pause and Previous/Next through media keys/Control Center; no seek, scrub, or Stop command. |
