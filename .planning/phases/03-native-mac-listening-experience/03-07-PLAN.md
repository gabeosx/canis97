## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Semantic state → assistive technology | Announced labels/values cross to VoiceOver and accessibility clients. |
| Keyboard/menu event → app command | Focused input and global app commands request listening behavior. |
| Appearance/layout → native semantics | Visual changes must not remove or redefine actions, focus, contrast, labels, or order. |
