## Corrections Made

### Phase boundary before assumptions review

- **Original assumption:** Phase 04.2 would deliver song favorites and possible playlist-service connections.
- **User correction:** Make Phase 04.2 the expressive UI/skin phase first and move local song favorites to Phase 04.3.
- **Reason:** The existing UI did not deliver the requested Winamp nostalgia; the user wanted macOS 8, MiniDisc, and Frutiger Aero-inspired themes with art and different window shapes, not palette changes.

No corrections were made to the revised expressive-skin assumptions; the user confirmed all of them.

## External Research

- macOS window behavior: SwiftUI can own masks, semantic hit shapes, and drag overlays while a narrow AppKit bridge owns transparent window chrome, exact finite sizes, restoration, and visible-screen clamping. A transparent rectangular window provides the visual silhouette without promising arbitrary per-pixel click-through behavior. Sources: [Apple window styles and restoration](https://developer.apple.com/documentation/SwiftUI/Customizing-window-styles-and-state-restoration-behavior-in-macOS), [WindowDragGesture](https://developer.apple.com/documentation/swiftui/windowdraggesture), [NSScreen.visibleFrame](https://developer.apple.com/documentation/appkit/nsscreen/visibleframe).
- Accessibility: semantic/source order should remain app-owned, targets and focus indicators must remain usable across silhouettes, decoration should be accessibility-hidden, and Reduce Motion should remove nonessential theme motion. Sources: [Apple Accessibility HIG](https://developer.apple.com/design/human-interface-guidelines/accessibility), [Focus and selection](https://developer.apple.com/design/human-interface-guidelines/focus-and-selection/), [Keyboards](https://developer.apple.com/design/human-interface-guidelines/keyboards).
- Original public identities: Apple restricts copied marks, icons, typefaces, graphics, and distinctive product appearance; Sony identifies MiniDisc-related marks; FRUTIGER AERO has a current US trademark application. These findings support original names/assets rather than replicas. Sources: [Apple IP guidelines](https://www.apple.com/legal/intellectual-property/guidelinesfor3rdparties.html), [Sony trademark terms](https://www.sony.co.jp/terms-of-use/trademarks.html), [USPTO application 99546718](https://tsdr.uspto.gov/#caseNumber=99546718&caseSearchType=US_APPLICATION&caseType=DEFAULT&searchType=statusSearch).
- Font redistribution: use system font tokens or separately reviewed redistributable app-owned fonts; do not load arbitrary fonts from imported packages. Sources: [Apple fonts](https://developer.apple.com/fonts/), [Inter license](https://github.com/rsms/inter/blob/master/LICENSE.txt), [IBM Plex license](https://github.com/IBM/plex/blob/master/LICENSE.txt), [SIL OFL FAQ](https://software.sil.org/oflt/).
