## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Subscriber action → presentation/bridge | Only an explicit Sign In or Retry action may create a new attempt and re-arm the handoff. |
| WebView cookie store → volatile handoff | A matched first-party cookie becomes one opaque in-memory credential; stale material must not cross attempt boundaries. |
| Volatile handoff → SiriusXMClient | A new credential still has no authority until client-owned native authentication and entitlement both succeed. |
