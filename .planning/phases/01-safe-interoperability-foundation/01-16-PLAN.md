## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Keychain bytes → opaque app credential | Persisted secret material is untrusted until bounded and staged for one explicit attempt. |
| Combined credential source → SiriusXMClient | Restored or WebView origin crosses through one opaque protocol and gains authority only after native auth plus entitlement. |
| Native terminal result → Keychain erasure | Every non-entitled restored result must revoke persisted material before presentation or later retry. |
| App composition → Xcode build graph | The new source must compile in the app without changing signing/release ownership. |
